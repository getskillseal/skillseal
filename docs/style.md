# Look and feel

A near-black, premium, restrained palette. Nothing shouts; the whitespace and
hairlines do the work. The blue seal is the one saturated colour, because it is
the one thing the product is about.

## Tokens

| Role | Value |
| --- | --- |
| Canvas | `#0c0c0e` |
| Panel / raised | `#161618`, hover `#1c1c1f` |
| Border | `rgba(255,255,255,.07)`, hover `.11` |
| Text | `#f4f4f5` / `#8a8a92` dim / `#5c5c63` faint |
| Primary CTA | pale yellow `#eeea86`, black text |
| Seal (identity) | `#1d9bf0` |
| Good / new | `#5bd97e` |
| Radius | pills for chips and tabs; 16–20px for cards and panels |
| Type | geometric sans (DM Sans), tight tracking; JetBrains Mono for counts and hashes |

## Motifs

- **Count badges.** A number lives in a pill next to its label: `Skills 193`, a
  category with its count, the cover's `193 skills · 27 categories · 0 to trust`.
- **Faceted shards.** Each card carries a low-poly field fading in from the
  right, seeded by the skill's name so no two are alike. Monochrome, a few
  percent opacity, never over text.
- **Status pills.** Small-caps outline chips, blue `Verified` first, then source
  and platforms.
- **Sort control** top-right of the grid; **pill filters** with live counts in
  the rail.

The motifs are drawn here, not taken from anywhere; only the sensibility is
borrowed.
